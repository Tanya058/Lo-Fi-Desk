# Lo-Fi Desk

**Lo-Fi Desk** is a modern productivity web app designed to make focused work sessions more comfortable and distraction-free. It combines a customizable **Pomodoro timer** with relaxing **Lo-Fi music and ambient sounds** such as rain, fireplace, and vinyl noise.

## Features

* **Customizable Pomodoro Timer** — Set focused work and break sessions according to your workflow.
* **Lo-Fi Music Player** — Choose from different Lo-Fi tracks while you work or study.
* **Ambient Sounds** — Add relaxing sounds such as rain, dark rain, fireplace, and vinyl.
* **Audio Controls** — Easily play, pause, and control your background audio.
* **Minimal Productivity Interface** — A clean workspace designed to keep distractions low.
* **Responsive Design** — Works across desktop and smaller screens.

## Tech Stack

* **HTML5** — Page structure and layout
* **CSS3** — Styling, animations, and responsive design
* **JavaScript** — Timer logic, audio controls, and application functionality

## Getting Started

### Run Locally

Clone the repository:

```bash
git clone https://github.com/Tanya058/Lo-Fi-Desk.git
```

Navigate to the project folder:

```bash
cd Lo-Fi-Desk
```

Then open `index.html` in your browser.

No additional dependencies or installation are required.
